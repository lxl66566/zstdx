| encoder-side FIXED-OFFSET ramp at MT job starts for decode-parallel stage B (suppress matches whose OFFSET sits below a 4-64 KiB floor near job starts, so pieces never wait on near-boundary reads) | piece-pipeline ceiling stays ~1.0-1.14× at every floor | the binding constraint is a crossing read's DEPTH below the cut (`start - src`), not its offset: a piece can start a copy the moment the source range is published, and a deep source (old bytes, published early by the previous piece) unblocks it regardless of how large the match's offset is. An offset floor suppresses exactly the wrong set (large offsets whose sources are deep and harmless) while leaving shallow-DEPTH reads (any offset, source just below the cut) untouched. The DEPTH-semantics ramp (crossing reads must reach ≥ D below the job start) is what works; it is landed, env-gated (see todo item 1) |
| emitting the ramp gate at probe-acceptance sites only (let backward match extension run to the window floor) | guarantee audit (executor-truth) finds shallow crossing reads at job starts whose probe was in-job: ml 12-23 at depths 400-2200 | backward extension is a COVERT leak: it walks source and match back in lockstep at constant offset, so a match probed in-job extends its source across the job start at shallow depth without any probe ever seeing the crossing. All 9 extension points need the gate's floor, and the floor is piecewise: an in-job source must stop AT the job start (extension is contiguous — passing the boundary drags the source through the whole forbidden band, and an extension dying inside the band emits an illegal read), while an already-deep source extends freely (it only gets deeper). A uniform `start - D` floor both allows the illegal band for in-job sources and disables extension entirely for deep ones |
